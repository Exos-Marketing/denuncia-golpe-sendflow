# Divulgação

A página só funciona se as pessoas souberem dela antes de serem abordadas. Ponha o link onde elas passam logo ao entrar.

## Descrição dos grupos

Logo abaixo da lista de números oficiais que você já usa:

```
⚠️ *CUIDADO COM GOLPISTAS!* Confie apenas nos números abaixo 👇
📱 +55 11 ...
📱 +55 11 ...

Recebeu mensagem de um número que não está nesta lista? Denuncie em suaempresa.com.br/denunciar-golpe
```

## Mensagem de boas-vindas (ou regras fixadas)

```
Ninguém da equipe vai te chamar no privado oferecendo desconto, vaga ou pedindo Pix.
Se alguém fizer isso, não responda, não clique no link e denuncie o número aqui:
suaempresa.com.br/denunciar-golpe

O número é bloqueado e retirado dos grupos.
```

## Página de obrigado e pós-compra

Uma linha na parte de segurança:

> Recebeu mensagem de um número que não está nesta lista? [Denuncie aqui](/denunciar-golpe/) e ele é bloqueado e retirado dos grupos.

## Página de verificação de número (se você tiver)

No resultado "este número não é da nossa equipe", um botão para `/denunciar-golpe/?n=<dígitos>`: a página abre com o número já preenchido.

## Dicas

- Use o link do seu domínio, não um encurtador desconhecido: quem acabou de ser abordado por golpista desconfia de link estranho.
- Agendar mensagem nos grupos é disparo. Combine o texto e o horário com quem cuida dos grupos.
